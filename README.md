# Racing Game 🏎️

A fun and interactive racing game built with HTML5, Canvas, and JavaScript!

## Features

- 🎮 **Smooth Controls**: Use arrow keys or WASD to control your car
- 🚧 **Dynamic Obstacles**: Avoid incoming obstacles that increase in difficulty
- 🛡️ **Power-ups**: Collect shields and boost power-ups
- 📊 **Scoring System**: Earn points by avoiding obstacles and collecting power-ups
- 📈 **Progressive Difficulty**: Game difficulty increases as you progress through levels
- 🎨 **Smooth Graphics**: Beautiful canvas-based graphics and animations

## How to Play

1. **Start**: Click the "Start Game" button on the welcome screen
2. **Move**: Use **Arrow Keys** or **WASD** to move your car left and right
3. **Avoid**: Dodge the red obstacles coming down the road
4. **Collect**: Grab power-ups:
   - 🔵 **Blue Shield**: Protects you from one collision
   - 🟡 **Gold Boost**: Adds 50 points to your score
5. **Score**: Survive obstacles to increase your score and level
6. **Game Over**: If you hit an obstacle without a shield, it's game over!

## Controls

- **Arrow Left/Right** or **A/D**: Move car left and right
- **Arrow Up/W**: Accelerate
- **Arrow Down/S**: Brake

## Game Mechanics

- **Score**: +10 points for each obstacle you pass, +50 for collecting gold
- **Levels**: Progress through levels as you accumulate points
- **Speed**: Game speed increases with each level
- **Difficulty**: More obstacles spawn at higher levels
- **Shield**: Protects you from one collision and disappears after use

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/dokky982/racing-game.git
   ```

2. Navigate to the directory:
   ```bash
   cd racing-game
   ```

3. Open `index.html` in your web browser
